# ApiTool 浏览器请求捕获扩展（Chrome MV3）

监听浏览器中**指定网页**的网络请求，将请求与响应回传给 ApiTool 桌面端的「请求捕获」模块，
自动生成接口文档，并可导出为 OpenAPI 3.0。

## 工作原理

- 扩展通过 Chrome 调试协议（`chrome.debugger`）附加到命中所配置规则的标签页，
  捕获完整的：方法、URL、请求头、Query、请求体，以及响应状态、响应头、响应体。
- 捕获的数据经 `POST /capture?token=...` 回传到桌面端独立捕获服务（默认 `http://127.0.0.1:8653`）。
- 桌面端「请求捕获」页可勾选记录，一键「生成接口并导入」项目，或「导出 / 复制 OpenAPI」。

## 安装步骤

1. 打开 Chrome，访问 `chrome://extensions`
2. 右上角开启「开发者模式（Developer mode）」
3. 点击「加载已解压的扩展程序（Load unpacked）」，选择本目录（`browser-extension/`）
4. 点击工具栏拼图图标，将「ApiTool 请求捕获」固定到工具栏

## 配置与使用

1. 在桌面端打开「请求捕获」页，复制页面上的**鉴权 Token**
2. 点击扩展图标，粘贴 Token，填写：
   - **监控网址**：每行一条，支持 `*` 通配，例如
     ```
     https://api.example.com/*
     example.com
     ```
   - 勾选「启用捕获」「抓取响应体」
3. 点击「保存」，再点「测试连接」确认能连通桌面端
4. 打开目标网页并进行操作（发起请求），捕获记录会实时出现在桌面端「请求捕获」列表中

> 注意：启用捕获后，被监听的标签页顶部会出现 Chrome 的「正在调试此浏览器」提示条，
> 这是 `chrome.debugger` 读取请求/响应体的正常表现。关闭捕获或「断开全部」后提示条消失。

## 与桌面端的关系

- 桌面端在启动时会**自动启动**捕获服务（端口 8653），并在 `syncserver/capture_token.txt`
  中持久化 Token，因此通常只需在扩展中配置一次 Token，重启桌面端无需重新复制。
- 捕获服务与现有「同步服务（8080）」相互独立，互不干扰。

## 文件结构

- `manifest.json` — 扩展声明（MV3）
- `background.js` — Service Worker：调试器连接管理 + 网络事件捕获 + 回传
- `popup.html` / `popup.js` — 弹出配置界面
