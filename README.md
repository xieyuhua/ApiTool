# ApiTool · 接口调试与文档工具

本地优先的 API 接口调试、管理与文档生成工具。基于 **Wails + Vue + Go** 构建为桌面应用，
同时内置可独立部署的**云同步/分享服务器**，实现「本地开发 + 云端分享」。

- 本地数据自动保存，无需登录即可使用
- 多项目 / 多目录 / 多接口管理
- 环境变量、前后置脚本、AI 自动生成字段说明
- 一键导出 Markdown / HTML / Word / OpenAPI 文档
- 两种分享方式：**网页代码（独立 HTML）** 与 **在线链接（本地或云服务器）**
- 云同步 / 多端共享：把项目推送到云端，其他设备拉取

## 二、安装与构建

### 环境要求
- Go 1.21+
- Node.js 18+
- Wails v2 CLI：`go install github.com/wailsapp/wails/v2/cmd/wails@latest`

### 构建桌面应用
```bash
# 安装前端依赖并构建
cd apitool
wails build
```
产物位于 `build/bin/apitool.exe`（Windows）/ `build/bin/apitool`（macOS/Linux）。

### 开发模式（热更新）
```bash
wails dev
```
会启动 Vite 开发服务器；也可在浏览器访问 `http://localhost:34115` 进行前端调试。

### 构建云同步 / 分享服务器（独立部署到云）
```bash
go build -o build/bin/apitool-server.exe ./server/cmd
```
运行：
```bash
apitool-server.exe -addr :8080 -data apitool-server-data
```
- `-addr`：监听地址，如 `:8080` 或 `0.0.0.0:8080`
- `-data`：数据存储目录（用户账号、项目、分享文档）

## 三、使用指南

### 1. 项目与目录
- 顶部项目下拉框右侧「⋯」菜单：**新建项目 / 重命名当前项目 / 删除当前项目**。
- 侧边栏「+ 目录」与目录右键「新建子目录」会**弹窗输入名称**后创建。
- 「+ 接口」支持直接粘贴带 Query 参数的完整 URL（自动解析地址与参数）。

### 2. 调试接口
- 在「调试」页填写方法、URL、参数、Header、Body。
- **环境变量替换**：URL 与参数值中可用 `{{变量名}}` 引用当前激活环境的变量，
  发送时自动替换为对应值（仅启用项生效）。
- **前后置脚本**：支持在请求前/后执行脚本（可用于动态签名、取响应字段等）。

### 2.1 参数设置（请求参数 / 响应参数 / 请求头）

切换到「参数设置」标签页，可维护接口的参数文档（会写入导出/分享的文档）：

- **请求参数**：请求 Body 的字段结构（`reqFields`）。支持嵌套对象/数组，
  可「粘贴 JSON 导入」「从请求体导入」「AI 补全字段描述」。
- **响应参数**：响应 Body 的字段结构（`respFields`）。可「粘贴 JSON 导入」
  「从最近一次响应导入」「AI 补全字段描述」。
- **请求头**：该接口的请求头（`headers`，键值对），调试发送时一并生效；
  **仅此一处**可编辑 Header，响应头不在接口定义中（详见下方说明）。

> **说明：Header 与请求/响应参数的关系**
> 每个接口只有一个「请求头」字段，**只属于请求**。原因：HTTP 协议中请求头和响应头是
> 两套独立的东西——请求头是客户端发给服务器的（如 `Authorization`、`Content-Type`），
> 响应头是服务器返回的（如 `Content-Type`、`Set-Cookie`）。
> - 在「参数设置」里编辑的 Header = 发送请求时携带的**请求头**；
> - 「接口调试 → 响应区 → 响应头」展示的是发送后服务器返回的**响应头**，
>   它是只读的、不会保存到接口定义中，仅用于查看。
> 因此「请求参数」「响应参数」的字段表格里本身**没有** Header 列，Header 只出现在「请求头」标签页。

### 3. 环境变量
- 「环境变量」面板以横向环境芯片切换（开发/测试/生产…），编辑区占满宽度。
- 每行变量：`启用 / 变量名 / 值 / 说明`，可任意增删。
- 切换「当前激活环境」后，调试时 `{{变量}}` 即使用该环境的值。

### 4. 文档中心（导出与导入）
入口：顶部「📄 文档中心」。
- **选择范围**：按目录层级选择要导出的接口范围。
- **导出格式**：
  - Markdown（`.md`）— 适合 Git 仓库、Wiki
  - HTML（`.html`）— 带目录导航的网页文档
  - Word（`.doc`）— 可用 Office / WPS 打开编辑
  - OpenAPI 3.0（`.json`）— 可导入 Swagger、Postman、Apifox
- **复制 Markdown**：直接复制到剪贴板。
- **导入文档**：支持 OpenAPI 3.0 / Swagger 2.0 / Postman Collection（JSON 与 YAML），
  导入内容归入独立目录（以 `导入-<文件名>` 为根目录）。

  **目录分组规则**：
  - OpenAPI / Swagger 按文档中的 `tags` 创建目录，并把接口归入对应 tag。
  - 兼容 Apipost 等工具：即使文档**未在顶层声明 `tags`**，只要各接口自带
    `tags: ["用户管理"]` 之类标签，也会自动补建目录并归类（解决「导入后所有接口平铺、
    没按目录创建」的问题）。
  - Postman Collection 按其 `item` 的文件夹层级还原为多级目录。
  - 未归入任何目录的接口会落到导入根目录，不会丢失。

### 5. 分享文档
在接口或目录的右键菜单 / 文档中心中打开「分享」对话框，提供两种方式：

#### 方式 A：网页代码（独立 HTML，推荐）
- 生成**完整且样式内联的 HTML 源码**，**不依赖任何服务端**。
- 可「复制网页代码」「导出 .html 文件」「浏览器预览」。
- 把文件发给任何人或部署到任意静态服务器，对方都能直接打开。

#### 方式 B：在线链接
- **云分享（已配置云服务器并登录）**：文档上传到云服务器，
  生成公网链接 `https://你的云服务器/s/<token>`，任何人都可在浏览器打开（无需安装本程序）。
  > 配置路径：设置 → 云同步，填写云服务器地址并登录。
- **本地分享（未配置云服务器）**：由本工具内置本地服务托管，
  同一局域网内他人可将 `localhost` 替换为你的局域网 IP 访问；公网访问需改用云分享。
- 支持设置**访问密码**与**有效期**（10 分钟 / 1 小时 / 1 天 / 7 天 / 长期），
  并可随时「停止」某个分享。

### 6. 云同步 / 多端共享
入口：设置 → 「☁ 云同步 / 多端共享」（或云同步弹窗内的开关）。
- 填写云服务器地址，注册或登录账号。
- **推送到云端**：按项目 ID 创建或覆盖云端同名项目。
- **拉取**：点击云端项目即可拉取到本地并切换。
- **自动同步（新增开关）**：在设置页或云同步弹窗中打开「自动同步云端」。
  - 开启后：每次编辑（防抖约 4 秒）自动把所有项目备份到云端，**防止本地文件损坏/误删导致数据丢失**；
    应用启动时自动拉取云端「比本地新」或「本地没有」的项目，实现多端无感同步。
  - 关闭后：退回原来的手动「推送 / 拉取」模式。
  - 冲突处理：若云端已有更新版本（HTTP 409），自动先拉取云端内容再合并，避免互相覆盖。
  - 多端同时离线编辑同一项目时采用「后同步者覆盖」（last-write-wins）；单人/单机防丢失完全没问题，
    多设备协作建议错开时间编辑。

> **关于「拉取」有什么用**：拉取 = 把云端某个项目下载到本机并切换使用。
> 在纯手动模式下，单机且从未推送过时云端为空、拉取无意义；开启自动同步后，
> 拉取主要作为「本地数据丢失后从云端恢复」或「拿别人共享项目」的兜底手段，日常由开关自动完成。

### 7. 内置同步服务（可选）
设置页可一键「启动服务」，桌面端同时作为同步服务器。
其他人可将云服务器地址填为 `http://你的IP:端口` 来连接（适合局域网或配合公网映射使用）。

### 8. AI 配置
设置页填写 OpenAI 兼容接口地址、API Key、模型，
用于自动生成字段描述（支持 OpenAI / DeepSeek / 通义千问 / 本地 Ollama 等）。

## 四、部署云分享服务器（公网访问文档）

1. 在云服务器上构建并运行同步服务：
   ```bash
   go build -o apitool-server.exe ./server/cmd
   apitool-server.exe -addr 0.0.0.0:8080 -data /var/lib/apitool
   ```
2. （建议）使用 Nginx 反代并配置 HTTPS 域名，例如 `https://api.your.com`。
3. 桌面端：设置 → 云同步，云服务器地址填 `https://api.your.com`，注册/登录。
4. 分享文档时选择「在线链接」，即得到 `https://api.your.com/s/<token>` 公网可访问链接。

### 云服务器提供的接口
| 方法 | 路径 | 说明 | 鉴权 |
| --- | --- | --- | --- |
| POST | `/api/register` | 注册账号，返回 token | 无 |
| POST | `/api/login` | 登录，返回 token | 无 |
| GET/POST | `/api/projects` | 列出 / 创建项目 | Bearer Token |
| GET/PUT | `/api/projects/<id>` | 获取 / 更新项目 | Bearer Token |
| POST/GET | `/api/share` | 创建 / 列出分享文档 | Bearer Token |
| DELETE | `/api/share/<token>` | 删除分享文档 | Bearer Token |
| GET | `/s/<token>` | 公开查看分享文档（可选 Basic Auth 密码） | 无 |

## 五、数据存储

- 桌面端本地数据保存在用户配置目录（如 Windows：`%APPDATA%/apitool/data.json`），
  所有接口信息（含最近一次请求与响应）自动保存。
- 云服务器端数据保存在 `-data` 指定的目录（账号、项目、分享文档）。

## 六、常见问题

**Q：分享的「在线链接」别人打不开？**
A：未配置云服务器时为本地分享，仅同局域网可访问。要公网访问，请部署云同步服务器并在
设置中登录，分享时即自动生成公网链接。

**Q：环境变量 `{{变量}}` 没被替换？**
A：请确认该变量所在环境为「当前激活环境」且「启用」开关已打开，变量名与 `{{ }}` 内一致。

**Q：项目名称无法修改？**
A：通过顶部项目下拉框右侧「⋯」→「重命名当前项目」修改。

**Q：如何把他人发来的接口文档导入？**
A：文档中心 → 导入，支持 OpenAPI / Swagger / Postman 的 JSON 或 YAML。

**Q：从 Apipost 导出的 OpenAPI 3.0 导入后，接口没有按目录分组？**
A：旧版本仅识别顶层 `tags` 数组，而 Apipost 常在接口内自带 `tags` 但未在顶层声明，
导致全部平铺。当前版本已支持「接口自带 tag 也自动建目录」。若导入后仍平铺，请确认
导出文件里每个接口带有 `tags` 字段；如为多级文件夹分组，OpenAPI 的 tag 是扁平字符串，
导入后为一级目录（不支持多级嵌套还原）。

**Q：开启「自动同步云端」后数据还会丢吗？**
A：本地每次编辑会防抖推送到云端，云端始终保留最新副本，可避免本地文件损坏/误删导致丢失。
但多设备同时离线编辑同一项目时后同步一方会覆盖先同步一方（last-write-wins），
重要协作建议错开时间或善用「拉取」兜底。

**Q：用 `npm run dev` 浏览器预览，点「生成分享链接 / 发送请求」报错
`Cannot read properties of undefined (reading 'main')`？**
A：这是预期行为——浏览器预览环境没有 Go 后端（`window.go` 由 Wails 运行时注入）。
程序已做安全兜底：会显示「当前环境未连接到 Go 后端…」的友好提示而非白屏崩溃。
要真正使用分享、云同步、发送请求等功能，请用桌面端：`wails build` 构建后运行，
或 `wails dev` 实时预览。

**Q：桌面端仍然报 `reading 'main'` 错误？**
A：说明 Wails 桥接未正确注入。请确认是用 `wails build` / `wails dev` 启动，
而非直接打开 `npm run build` 产出的 `dist`。如仍异常，尝试删除 `frontend/dist` 与
`build/bin` 后重新 `wails build`。
